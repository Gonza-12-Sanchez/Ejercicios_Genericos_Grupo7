## Ejercicios Resueltos

Nuestro grupo seleccionó y realizo los siguientes 2 ejercicios:

### Ejercicio 3 - Par<A,B>
* Crear una clase genérica que almacene dos valores.
* Agregar un método: `invertir()` que devuelva el par invertido.

### Ejercicio 4 - Calculadora
* Implementar métodos para: `promedio()` y `maximo()`.
* Trabajar con listas de números.
